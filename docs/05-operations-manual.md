| Mon | PM (1.5h) | List 4–6 · answer messages · send liker offers · ship |

| Wed | PM (2.5h) | **Photo shoot #1 (30 items)** · list 4–6 · ship |

Claude's standing weekly jobs: write all listing copy from photo batch notes, comp-check
flagged items, draft social captions, analyze the ledger, update pricing/markdown queue,
monitor trends.

## 2. Shipping SOP

- Supplies: poly mailers (6×9, 10×13, 14.5×19), thank-you cards, tape. Cost/order ≤ $0.50.
- Depop label (USPS Ground Advantage) by weight tier; **weigh once, set the right tier at
  listing time** — label upcharges eat margin.
- **Ship within 24h, always.** Same-day when possible: reliability boosts every listing's rank.
- Pack station stays set up permanently: mailers, tape, printer, scale in one spot — packing
  an order takes 90 seconds, not 10 minutes.
- Tracking auto-uploads via Depop labels. For other platforms, Vendoo/platform labels same rule.

## 3. Customer service scripts (paste-ready)

- **Lowball:** "Thanks for the offer! The lowest I can do on this one is $X — it's [rare/
  vintage/pristine]. I'll send that as a counter 😊"
- **Measurement ask:** answer within the hour with exact numbers; then: "It'd fit a [size]
  really well — want me to bundle it with anything for 10% off?"
- **Item issue:** apologize once, offer partial refund or return immediately, no argument.
  Protect the review; the algorithm reads your reputation.
- **Where's my order:** tracking number + "Shipped [day]! USPS sometimes lags a day on
  scans — it's on its way 💌"

## 4. KPI dashboard (tracked in the ledger, reviewed every Sunday)

| KPI | Target | Red flag |
|---|---|---|
| New listings/week | ≥ 30 | < 20 |
| Sell-through (30-day) | ≥ 30% | < 15% |
| ASP | phase target (doc 04) | falling 2 wks straight |
| Blended COGS | ≤ phase ceiling | > ceiling 2 wks |
| Avg days-to-sale | < 25 | > 40 |
| Ship time | < 24h | any >48h |
| Review average | 5.0 | any 4★ or below |
| Offer→sale conversion | ≥ 15% | < 8% |
| Revenue vs roadmap (doc 06) | on plan | 2 months behind → strategy review |

## 5. Inventory system

- Every item: **SKU on a masking-tape tag + row in `tools/inventory_tracker.csv`** at intake.
- Storage: numbered bins (SKU prefix = bin number). Sold item → find in seconds.
- Monthly stock audit: 15 minutes, count 2 random bins against the ledger.
